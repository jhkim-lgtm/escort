01 — WHY NOW

데이팅 앱은 피로해졌고,
사주는 다시 가장 힙한 언어가 됐다.

무한 스와이프는 선택 피로만 남긴다. 반대로 2030에게 사주·궁합은 오락이자 자기 이해의 언어로 부활했다. "사주가 잘 맞는데, 외모도 괜찮고, 검증까지 된 사람" — 이 세 가지를 동시에 주는 서비스는 아직 없다.

PROBLEM 1무한 스와이프 피로

하루 수백 장 프로필 → 선택 마비 → 이탈. 우리는 하루 1~3장의 카드만 보낸다. 희소성이 곧 가치다.

PROBLEM 2검증 부재

사진·직업·매너 어떤 것도 보증되지 않는다. 우리는 지인 추천 2인 + 신원 인증 + 만남 후 상호 평점으로 3중 검증한다.

PROBLEM 3앱 설치의 낙인

폰에 깔린 데이팅 앱은 들키는 순간 리스크다. 카카오톡 채널로 카드를 받으면 설치할 앱 자체가 없다.

03 — HOW IT WORKS

남자는 확신에 지불하고,
여자는 만남으로 수익을 만든다.

1
웹 링크로 가입 + 카카오 채널 추가

앱 설치 없음. 카카오싱크로 이름·연락처·생년월일 자동 수집 → 사주 프로필 생성. 채널 추가 기념 웰컴 카드 3장 무료.

2
친구톡으로 인연 카드 수신

사주 궁합 점수 + 검증 배지가 붙은 카드가 카톡으로 도착. 48시간 타임어택 — 수락이든 거절이든 결정해야 다음 카드가 온다.

3
무료 소진 후 카드 열람권 5만원

더 보고 싶으면 지불한다. 카드 1장 = 5만원. 헤비 유저용 PASS 멤버십(월 29만, 카드 8장 + 우선 배정).

4
연락처 교환권 35만원 (30~50만 구간)

수락 + 상대 수락 시 매니저가 카톡으로 연락처 전달. 상대 거절 시 전액 환불 — 결제 장벽을 심리적으로 제거하는 핵심 장치.

1
초대 코드로 가입 → 3중 심사

기존 멤버 추천(슬롯 2개) + 프로필 심사 + 신원 인증. 심사 통과 즉시 내 추천 코드 발급 + 피추천 축하금 3만원.

2
카드에 선택되면 만남 여부 결정

내 카드가 오픈·수락될 때마다 알림. 만남 여부는 전적으로 본인 선택 — 거절해도 불이익 없음.

3
만남 성사 = 매칭 리워드 3~10만원

연락처 교환 성사 시 기본 3만원, 만남 후 상호 후기 완료 +3만, 평점 4.5 이상 +4만. 명목은 '후기 리워드' — 만남의 대가가 아니라 데이터의 대가로 설계 (법률 섹션 참조).

4
친구를 초대하면 평생 리워드

내 코드로 가입한 친구가 매출을 일으킬 때마다 티어 요율(5~12%)만큼 평생 지급. 친구가 인기 많을수록 나는 놀아도 돈이 들어온다 — 이게 성장 엔진.

⚠️ 2단계(친구의 친구) 보상은?

현금은 1단계(직접 추천)까지만. 친구의 친구에게서 발생한 매출에 현금을 지급하는 순간 3단계 판매조직 + 후원수당 구조가 되어 다단계판매업 등록 대상이 된다(미등록 시 7년 이하 징역/2억 이하 벌금 — 법률 섹션).

대신 2단계는 비금전 혜택으로 설계: 내 친구가 데려온 친구가 활동하면 → 파티 초대권, 카드 우선 배정, MADAM 승급 가점. 구조의 재미는 유지하고 리스크는 제거.

08 — LEGAL REDLINES

이 사업의 성패는 지급 명목 설계에 달렸다.

구조 자체는 만들 수 있다. 단, 아래 네 가지 선을 넘는 순간 형사 리스크가 된다. 설계 단계에서 자문 변호사 검토 1회는 필수.

HIGH — 형사

① 미등록 다단계 (방문판매법)

보상이 3단계 이상 조직으로 흐르면 다단계판매업 등록 대상 — 미등록 영업은 7년 이하 징역 또는 2억원 이하 벌금. 등록하더라도 후원수당 총액은 매출액의 35% 상한.

→ 우리의 답: 현금 보상은 직접 추천 1단계로 제한. 2단계는 비금전 혜택만. 전체 보상 지급률도 35% 이내로 설계해 등록 전환 시에도 안전.

HIGH — 형사

② '만남의 대가' 프레임 (성매매알선 오해)

"만나주면 돈을 준다"로 읽히는 순간 유사 조건만남 플랫폼으로 해석될 리스크. 지원금 명목(헤어·메이크업비)을 만남 완료에 연동하면 더 위험.

→ 우리의 답: 지급 트리거를 만남이 아닌 데이터 행위에 건다 — 프로필 유지 리워드, 상호 후기 작성 리워드, 평점 우수 리워드, 추천 리워드. 금액 상한(건당 10만)과 월 캡. 오프라인 만남 강제 조항 금지, 여성의 거절권 100% 보장 문구 명시.

MID — 행정

③ 업종 신고·표시의무

결혼 목적 중개를 표방하면 결혼중개업법상 국내결혼중개업 신고 대상. 데이팅(교제) 서비스로 포지셔닝하면 통신판매업 신고 + 전자상거래법 표시의무 + 환불 규정 정비로 충분. 35만원 결제 상품은 환불 조건(상대 거절 시 100%)을 약관에 명문화.

MID — 세무·개인정보

④ 리워드 지급의 세무 처리

여성 리워드·추천 수수료는 사업소득 3.3% 원천징수(연 단위 기타소득 처리 검토), 지급명세서 제출. 연락처·생년월일·사주 정보는 민감정보급 — 개인정보 처리방침 + 수집·이용 동의 설계, 연락처 전달은 상호 명시 동의 로그를 남긴다. '에스코트' 명칭은 유흥 연상으로 카카오 채널·PG 심사 리젝 리스크 → 대외 브랜드는 별도 검토.
